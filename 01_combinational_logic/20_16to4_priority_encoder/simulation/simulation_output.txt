--------------------------------------------------
DESIGN DESCRIPTION
--------------------------------------------------

A 16:4 Priority Encoder converts sixteen input
lines into a four-bit binary output.

When multiple inputs are HIGH, the highest-indexed
input receives priority.

Output Signals:
Y     : 4-bit encoded output
Valid : Indicates at least one active input
