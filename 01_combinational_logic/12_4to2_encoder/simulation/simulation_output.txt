--------------------------------------------------
DESIGN DESCRIPTION
--------------------------------------------------

The 4:2 Encoder converts one of four active input
lines into a 2-bit binary output.

An additional Valid output indicates whether
exactly one input is HIGH.

Inputs:
- D0
- D1
- D2
- D3

Outputs:
- Y1
- Y0
- Valid

--------------------------------------------------
VERIFICATION METHODOLOGY
--------------------------------------------------

- Self-checking SystemVerilog testbench

- Independent reference model
- Case inequality ( !== ) comparison

- Invalid input pattern checking
