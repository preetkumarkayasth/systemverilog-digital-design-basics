--------------------------------------------------
DESIGN DESCRIPTION
--------------------------------------------------

The 4-bit magnitude comparator compares two
unsigned 4-bit binary numbers A and B.

It determines whether:
- A is greater than B
- A is less than B
- A is equal to B

Inputs:
- A[3:0]
- B[3:0]

Outputs:
- A_GT_B
- A_LT_B
- A_EQ_B

--------------------------------------------------
VERIFICATION METHODOLOGY
--------------------------------------------------

- Self-checking SystemVerilog testbench
- Exhaustive testing of all 256 input pairs
- Independent reference model
- Case inequality ( !== ) comparison
- Automatic PASS/FAIL counting
- Nested-loop based verification
